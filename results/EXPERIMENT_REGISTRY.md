## 1. Official Results

Two evaluation batches, both produced by `kfold_patch/evaluate_kfold.py` with the audit fixes E-4, E-5, E-6, D-1, D-2 in place:

* **Sept 8, 2026** — B4 / V2S / VGG16 models, run on 4× A100 via `scripts/run_all_evaluations.sh` (~59 min).
* **Oct 14, 2026** — the four October (post-audit) runs: HPO-champion EfficientNetV2M (CAB1 trial 21, CAB2 trial 32), CAB1 B4 HPO trial 52, and the CAB2 B4 retrain. The B4 pair was evaluated on 4 GPUs in parallel, one split per GPU, in 25 min.

> ⚠️ **Not a like-for-like comparison.** The B4 / V2S models were trained Aug 24 – Sep 1, *before* the Sept 8 audit fixes that require retraining (T-1…T-5, D-1, D-2, A-2, A-4, A-5 — see [`docs/CODEBASE_AUDIT.md`](../docs/CODEBASE_AUDIT.md)). The V2M models were trained in October *with* those fixes **and** with HPO-tuned configs. The B4 → V2M gain therefore mixes three effects: backbone, hyperparameters, and bug fixes.

## 5. Cross-Dataset Evaluation and Fine-Tuning (R3D, CVC-FP, WAFFLE)

Write-up and comparison with the paper and SOTA: [`COMPARISON_paper_sota.md`](COMPARISON_paper_sota.md).

**Data.** `kfold_patch/create_cross_tfrecords.py` builds 3-class TFRecords (bg / walls / openings = doors + windows) in `data/tfrecords/{r3d,cvc,waffle}/`: R3D official train (179) and test (53), CVC-FP all (122), and WAFFLE benchmark all (109 of 110; `StephansdomBauHistorie` excluded because its mask is misaligned).

**Zero-shot** (Nov 5, 9 and 10, 2026). `kfold_patch/evaluate_cross_dataset.py` runs all 10 fold models of each CAB1/CAB2 × B4/V2M combination (plus the CubiCasa5k and Zeng VGG16 baselines on R3D), mapping the 6 CubiCasa classes to the 3 target classes. `kfold_patch/summarize_cross_dataset.py` writes `cross_dataset/SUMMARY.md`. Outputs are `cross_dataset/{r3d_test,r3d_all,cvc_all,waffle_all}_kfold_<model>_<backbone>_<ts>.txt` plus `_fold_cms.npy`.

**Fine-tuning** (Nov 9–11, 2026). `kfold_patch/finetune_cross_dataset.py`, launched by `scripts/run_finetune_cross.sh` (WAFFLE: `scripts/run_waffle_all.sh` runs zero-shot and then fine-tuning, all on GPU 0), then `kfold_patch/summarize_finetune.py` writes `finetune/SUMMARY.md`.
* Starts from one CubiCasa fold checkpoint per combination (listed in the launcher). The backbone is frozen, so only the decoder is fine-tuned. Same asymmetric unified focal loss; the 6-class softmax is merged to 3 classes.
* Splits: R3D uses 143 train / 36 val (seeded, from the 179 official train plans) and the official 53-plan test. CVC-FP and WAFFLE use 5-fold CV, 60/20/20, with test confusion matrices pooled over folds.
* Augmentation: rot90, flips, scale 0.8–1.2, 512 crop, brightness/contrast, grayscale, blur, noise, JPEG.
* Every run also reports zero-shot and AdaBN (BN statistics recomputed on the unlabelled target train images) on the same test split.
* Each run writes `finetune/<ds>_<model>_<backbone>_split<k>_<ts>.json` (confusion matrices, metrics, epochs) and `models/finetune/<same tag>/best.weights.h5`. Checkpoints are kept only for the current results (44 runs, 3.0 GB). The superseded passes' checkpoints were deleted on Nov 10, 2026; their JSONs still list the old `weights` paths. Logs are in `logs/finetune/`.

| Pass | Dataset | LR / max epochs | GPUs | Runs | Status | Location |
|:-----|:--------|:----------------|:-----|:----:|:-------|:---------|
| 1 (Nov 9) | R3D + CVC | 1e-4 / 150, geometric aug only | 4 | 6 of 24 | interrupted when the session ended | `finetune/lr1e-4_geomaug/` (results only) |
| 2 (Nov 9) | R3D | 1e-5 / 150 | 0–1 | 4 | ✅ **current R3D result** | `finetune/` |
| 2 (Nov 9) | CVC | 1e-5 / 150 | 0–1 | 20 | superseded (most runs still improving at the cap) | `finetune/cvc_lr1e-5/` (results only) |
| 3 (Nov 10) | CVC | 3e-5 / 300 | 0 | 20 | ✅ **current CVC result** (all converged, ≤158 epochs) | `finetune/` |
| 4 (Nov 10–11) | WAFFLE | 3e-5 / 300 | 0 | 20 | ✅ **current WAFFLE result** (all converged, ≤72 epochs) | `finetune/` |

Headline (mean IoU of walls + openings):
* R3D: zero-shot 66–69 → fine-tuned 80.1–80.9. Walls IoU 91.2–93.4 beats the paper's 90.
* CVC-FP: zero-shot 44–48 → fine-tuned 72.0–73.8 (CAB2 B4: 64.4). Walls IoU 79–81 is still below the paper's 88–91.
* WAFFLE: zero-shot 38–39 → fine-tuned 54.7–57.1 (walls IoU 74–76, openings 35–38); the four combinations are tied. Per-class zero-shot comparison with the WAFFLE paper (Nov 11): `kfold_patch/eval_waffle_perclass.py` via `scripts/run_waffle_perclass.sh` on `data/tfrecords/waffle/waffle5_all` (bg/walls/doors/windows/interior), outputs `cross_dataset/waffle5_kfold_*`. It covers the 4 CAB combinations and the CubiCasa5k/Zeng VGG16 baselines. CAB walls IoU is 54.5–58.1 vs the paper's CubiCasa5K model at 48.8 (diffusion model 63.2).
* AdaBN makes every model worse on all three datasets.

**Overview (Nov 11, 2026).** [`OVERVIEW_all_datasets.md`](OVERVIEW_all_datasets.md) puts every dataset in the same 3-class format, generated by `kfold_patch/summarize_all_datasets.py` into `ALL_DATASETS_tables.md`. For CubiCasa5k, the per-fold 6-class test confusion matrices were re-exported (`kfold_patch/export_cubicasa_cms.py`, `scripts/run_export_cubicasa_cms.sh` → `official/test/*_fold_cms.npy`); they match the official result files to within 0.01 IoU points. The CubiCasa5k and Zeng VGG16 baselines were also run zero-shot on CVC-FP and WAFFLE.

## File Naming Convention

```
{split}_kfold_{model}_{backbone}_{YYYYMMDD-HHMMSS}.txt
```

| Field | Values |
|:------|:-------|
| `split` | `test` (400 samples) · `val` (4,600 out-of-fold) |
| `model` | `cab1` · `cab2` · `cubicasa5k` · `zeng` |
| `backbone` | `EfficientNetB4` · `EfficientNetV2S` · `EfficientNetV2M` · `VGG16` |

The evaluator writes new files to the `results/` root. Move them into `official/` (or `archive/`) once they're reviewed.
