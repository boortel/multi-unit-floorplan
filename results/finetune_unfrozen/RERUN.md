## How to rerun (one at a time, to avoid OOM)

Check first that the GPU is visible: `nvidia-smi` and
`python -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"`.

Run the three jobs **sequentially** on a free GPU. Do not use `run_finetune_unfrozen.sh` for this, because it would
start all 3 missing runs in parallel lanes:

```bash
cd /workspaces/multi-unit-floorplan
export TF_FORCE_GPU_ALLOW_GROWTH=true CUDA_VISIBLE_DEVICES=0
CAB1_V2M="models/cab1_cab1_hpo_trial21_v2m_EfficientNetV2M_16,32,64,128,256_cubicasa5k_20261005-034025/1"
CAB2_V2M="models/cab2_cab2_hpo_trial32_v2m_EfficientNetV2M_16,32,64,128,256_cubicasa5k_20261012-201652/4"
COMMON="--out results/finetune_unfrozen --models_out models/finetune_unfrozen --unfreeze"
(
python kfold_patch/finetune_cross_dataset.py --model cab2 --backbone EfficientNetV2M --checkpoint "$CAB2_V2M" \
  --dataset r3d --split 0 --lr 1e-5 --epochs 150 $COMMON > logs/finetune_unfrozen/r3d_cab2_EfficientNetV2M_split0.log 2>&1
python kfold_patch/finetune_cross_dataset.py --model cab1 --backbone EfficientNetV2M --checkpoint "$CAB1_V2M" \
  --dataset cvc --split 0 --lr 3e-5 --epochs 300 $COMMON > logs/finetune_unfrozen/cvc_cab1_EfficientNetV2M_split0.log 2>&1
python kfold_patch/finetune_cross_dataset.py --model cab2 --backbone EfficientNetV2M --checkpoint "$CAB2_V2M" \
  --dataset waffle --split 1 --lr 3e-5 --epochs 300 $COMMON > logs/finetune_unfrozen/waffle_cab2_EfficientNetV2M_split1.log 2>&1
python kfold_patch/summarize_finetune.py results/finetune_unfrozen > results/finetune_unfrozen/SUMMARY.md
) &
```

These commands overwrite the failed logs. Expected time is about 1–1.5 h in total.
